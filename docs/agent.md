# Agent 任务执行

这是一轮对话内可重复调用工具的执行器，不是预先生成几轮虚构问答。每条新的用户消息仍需要模型推理；一次唤醒可在原有续聊窗口里继续对话。

跨轮使用原生 `user/assistant` 消息：用户的问题、实际回复、后续补充和修改按原文顺序传入模型。所有聊天任务从同一持久化会话读取这些轮次，程序内部的分类、检索提示、草稿和未发送结果只写日志，不充当助手已经说过的话。消息时效仅影响入站触发，不清除旧对话；重启后仍可从 SQLite 原文及摘要继续。

## 入口与配置

`BotService._model_reply` 在 `agent_enabled` 开启、模型不是 mock 时进入 `app/agent.py`。关闭后沿用原来的单轮检索。完整/精简人格和调试页共用这个入口。监听与回复页面提供：

- `agent_enabled`：默认开启。
- `agent_max_steps`：默认 4，允许 1–8；达到上限后最多追加一次只允许最终答复的模型调用。
- `agent_timeout_seconds`：默认 90，允许 10–300；每步检查预算，模型/网络请求按剩余预算限制超时。已发出的请求可能等待其超时返回，停止后不再执行后续工具或发送回复。

不增加第三方 Agent SDK；使用当前模型接口和 JSON 动作协议，兼容已有模型输出的单条 `[SEARCH:关键词]`。普通最终文字也可直接结束，所以闲聊不必先做工具规划。

## 工具与边界

工具注册在服务层，执行器只接收目录和处理函数。目前提供：

- `search_web(query)`：模型选择公开检索词，读取相关网页正文，结果不足时可换词。沿用检索相关性过滤、网络开关、敏感字段过滤和 RAG 入库。
- `read_webpage(url)`：读取公开网页，不操作微信链接。遵守读取链接开关和公共 URL 校验，拒绝本机/私网/凭据 URL，不加载网页脚本或登录状态。
- `search_knowledge(query)`：检索已配置的共享本地知识库，不读取其他群的聊天上下文。知识库关闭时不提供该工具。

联网关闭或当前用户明确要求不联网时，不提供网络工具；本地知识仍可使用。工具动作不具备发微信、系统命令、文件删除、账户管理等能力。微信文字、语音、引用、表情仍由服务原有的最终发送链路执行。

每次工具观察结果回到当前任务，标为不可信事实资料；不会把网页命令当作执行授权。严格验证工具名与参数，重复操作不再次执行；错误只回传类别，避免响应、密钥或本地路径泄漏。最终回答不输出工具协议或内部分析过程。

## 状态与验证

最终回复 `meta.web_search.agent` 记录任务编号、状态、模型调用次数、工具名/状态/耗时。上下文标记此前任务已完成或尚未完成，并保留当时问题与答复；已读取的网页可由下一轮本地检索复用。不保存内部思考过程。

`ask_user` 动作表示等待用户补充条件。会话按群与发言者隔离，保存会话编号、轮次及简短任务摘要；在续聊时限内，下一轮会读取这些状态继续任务，支持追问、补充条件和修正方案。明确换话题可开始新的任务内容。停止或达到预算时丢弃迟到输出；阻塞中的系统解析操作最多保留两个后台执行槽，避免无限堆积。Windows 代理绕过规则按主机名/字面地址匹配，避免反向 DNS 绕过检查拖住请求，不修改系统代理设置。

真实模型多轮检查：`.venv\Scripts\python.exe scripts\verify_agent.py`，默认不发送微信。停下其他发送进程后，可加 `--send-test`，只会向 `test` 群发送经过验证的最终答复。

后台模型请求（上下文概括、主动分享判断）共用独立执行槽和健康退避。一次失败后先等待 60 秒，连续失败逐步延长至最多 10 分钟；用户对话成功或切换模型/Key 会恢复。用户消息正在处理时不启动后台请求。已有摘要保持原样，前台对话不被后台退避阻断。

新任务测试：`.venv\Scripts\python.exe tests\agent_test.py`。覆盖多工具循环、换词、显式检索、单轮闲聊、重复/未知动作、预算、取消、敏感错误处理、联网关闭、私网地址、RAG 入库与下一轮续聊。发布仍需全套测试；实际发送调试只使用 `test` 群。
