# 本地新增功能（待发布）

设置页新增「推理强度」「无限制模式（角色扮演）」「浏览朋友圈与评论」「基沃托斯新闻来源」。旧配置会补入默认值，朋友圈自动评论默认关闭，中档维持现有调用行为。

## 朋友圈

自动评论默认关闭。开启并保存后，程序连接微信时按所设间隔（默认30分钟）检查近24小时的文字动态。模型可以选择跳过；自己的动态、已有本人评论、过期或无文字动态跳过。一次只处理一条，以免打断正常回复。当前依据文字理解，不能声称看过图片或视频。

「读取并预览评论」只生成预览，不提交评论。自动提交要求数据库目标唯一、UIA完整正文和作者相符、有可核对的输入与发送控件；不截图、不图像匹配、不选择近似目标。微信未暴露所需控件时记录未发送。发送前写入收据，已提交但确认未知时不自动重发；评论记录损坏时停止提交。保留用户草稿，关闭开关后取消尚未提交的评论。

当前桌面工具报告 coordinate input geometry is unavailable，未在真实朋友的朋友圈发送调试评论。功能的实际UI兼容性仍需在允许的环境确认；不会把模拟测试当成真实发送成功。

## 推理强度

|---|---:|---:|---:|
| 轻度 | 0.6倍 | 2 | 90秒 |
| 中 | 原值 | 4 | 90秒 |
| 高 | 2倍 | 6 | 135秒 |
| 极高 | 4倍 | 8 | 180秒 |

这些是单次请求和任务的可用空间，不是实际消耗的保证值，也不是每日限额。模型能直接回答时依然直接结束。已有用户自定义工具步骤、任务时长作为相对基线，中档完全保留。官方DeepSeek非中档采用相应thinking/reasoning_effort字段；普通兼容中转仅调整通用输出空间、提示和工具深度。中档不额外启用原请求没有的思考参数。日常气泡字数、人格、概率规则保持原设置。

## 新闻

30个不同站点逐站查询，另保留国服/日服官方接口、Nexon、Steam、官方B站动态等渠道。搜索引擎只是发现入口，不把重复搜索入口算作独立来源。所有候选仍须过原有发布时间、正文证据、24小时与跨日去重检查；没有可核实新消息就诚实说明。不是承诺每天30站都有新稿或均可访问。目录见设置页，结果状态见新闻采集报告和日志。


## 高消耗（精简前模式）

新增可单独选择的高消耗档；不会自动替换当前档位。依据 data/backups/token-efficiency-20261104-192021 的精简前源码对照恢复，非把极高档改名。输出空间和工具步骤回到用户配置基线，通过发送更完整的上下文与证据、使用原详细提示布局、恢复后台任务判断频率来还原原模式。实际token消耗依聊天与活跃情况变化，不承诺固定倍数。

恢复：分类与摘要重新带同聊天完整上下文；分享/新闻任务恢复完整上下文与摘要；网页正文保留原先2200字的头部证据视图、视频说明1600字、字幕2400字；暖场不再依赖精简模式的相同消息签名去重唤醒。原有每群权限、概率与免打扰仍生效。

不回退：群聊隔离、真实入站方向、具体消息引用、语音能力与失败回退、最新自然气泡规则、消息时效、角色称呼、模型输入输出日志、缓存统计及安全修复。新日记和朋友圈评论保留只使用必要资料的隐私边界。最新用户要求的清楚、简洁中文表达在所有档位（包括高消耗）生效。


## 无限制模式（角色扮演）

在「设置 → 推理强度」单独开启并保存，默认关闭，与五档推理强度独立。保持当前选定角色的名字、性格、背景、称呼、关系、记忆和音色，只放宽话题和表达边界；不自动换成阿洛娜或另一个人格。虚构情境可以描写角色的人类生活与动作。正常问题先回答具体内容，不用“这个话题还是别继续了”等空泛话术阻断；接入模型服务本身的规则仍有效。

事实问答、联网搜索、新闻和已执行操作仍须真实，不把虚构经历写成事实。日记和朋友圈继续保留原有隐私范围。该模式不会关闭消息时效、入站方向或会话核对。

## 消息时效与防重复

「监听与回复」的消息时效默认10分钟，可自行调整。除入站时检查，排队后开始生成、后续模型调用、等待发送、文字提交前及语音合成后的录音前也检查；一旦超时，停止剩余回复。已经开始的单次微信发送不能撤回。过期消息保留原接收时间并标记为背景，摘要不删除，不作为新的待答问题。手动测试、新闻与朋友圈调度不套用聊天消息时效。

同一条已成功回复的入站记录不重复生成；相同回答里的重复气泡会去重。短时间内再次生成完全相同的答复时，只尝试修正一次，再按是否必须回复处理；明确要求“再说一遍”或明确声音请求不会被历史相同文字误挡。引用发送返回失败但数据库已确认同一条内容发出时，不再回退重发普通文字。

新闻调度每25秒仍正常检查；同一群、同一天、同一发送时间和相同未发送原因只记录一次状态日志。日期、发送时间或结果变化后重新记录，关闭的目标会清除内存状态。此优化不消耗正式新闻名额，不改发送窗口和失败重试。

## 主动评论的使用

「设置 → 浏览朋友圈与评论 → 自动浏览并评论」开启并保存后，连接微信即可定时主动检查，不需要每次点击预览。默认检查间隔30分钟，可改为5–1440分钟。本机已按本次用户授权开启；新安装仍默认关闭。模型根据当前角色和动态可见文字决定评论或跳过，不使用其他私聊作为评论素材。

每轮最多提交一条；不评论自己的动态、旧动态或已处理动态。UIA在有限视口内寻找完整正文、作者和时间一致的目标；未找到、用户有草稿或微信不提供可核对的发送控件时跳过。不会调用上游截图识别的发送接口。预览不会发送评论，也不会延后下一次自动检查；实际未发送/结果未知的原因写入日志。
