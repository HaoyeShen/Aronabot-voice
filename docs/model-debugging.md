# 模型日志与角色语音

运行日志中，每次模型调用都有「用途」和「调用」编号。输入包含 System、当前消息、上下文及工具结果；接口输入展示实际请求结构，原始输出在回复解析、字数检查和重写之前记录。接口重试也会记录，错误和空输出不会被当成成功回答。文字内容不截断，沿用现有本机轮转日志；密钥、管理员密码会遮蔽，图片的 Base64 编码仅显示类型/长度摘要。

人格页面选择角色的「编辑」，可选择语音音色并分别填写语速、音调和音量。选择「跟随全局音色」可保留旧行为；参数留空使用所选音色参数，设置后只影响该角色，不修改共享音色。音色新增和管理仍在监听与回复页面。角色语音模型只调整语速和音量，音调对 Edge 音色生效。手动测试指定音色时，不被群聊人格覆盖。

收到的微信图片继续由现有适配器下载/解密；达到回复条件后，直接将图片交给回复模型，不另发一轮「描述图片」请求。Agent 工具循环可保留原图。续聊可引用近期同群图片，时间沿用续聊超时设置；只保存本地图片路径，不把图片编码写入 SQLite 聊天正文。每轮最多附三张、单图文件不超过 20 MB，发送时压缩为最长边 1280 像素的 JPEG。模型需启用并实际支持视觉输入；缺图、损坏或不支持时如实说明，不编造看图结果。
