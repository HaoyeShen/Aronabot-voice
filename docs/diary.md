# 阿洛娜的今日日记

在「设置」中开启，默认北京时间22:00，可改时间。软件和微信需保持运行；当天错过时刻后启动，会尝试当天日记，不补发多天旧日记。发行版默认关闭，本机按用户授权开启。

「生成 / 查看日记预览」只生成本地草稿，不发布。22:00前预览后，当天活动若有变化，会在正式发布前重新整理。提交前封存正文，重试复用草稿，不反复调用模型。

「立即发布今日日记」点击即生成并发布到朋友圈，无需等待22:00，也不要求先开启自动日记；需先启动机器人并连接微信，使用当前配图选项。当天已发布的不再重复发，自动时刻也会跳过；结果不明确时先核对朋友圈，不盲目重发。

日记只提供机器人当天回复、语音、新闻、分享和联网统计，不提供群名、昵称、聊天原文；生成后再过滤私人标识和凭据。使用阿洛娜人格，不受聊天气泡限制，可附一张内置图片，不用私人导入表情包。

本地文件为 `data/diaries/YYYY-MM-DD.md` 与 `data/diary_state.json`，均不上传发行包。状态包括 draft、publishing、published、uncertain；损坏状态不自动重置。提交前先保存 publishing；结果未确认或提交时崩溃不自动重发，请核对朋友圈。

朋友圈 UI 操作共用微信适配器的 UI 锁；已有用户编辑窗口时不覆盖。实际文件选择、正文编辑和发表按钮按原生控件定位；路径和正文校验后只点击一次发表。没有纯文字发表入口的微信版本需开启配图。成功后恢复聊天页，避免影响正常回复。
