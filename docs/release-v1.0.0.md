## 下载

- `windows-x64.zip`：Windows 10/11 便携版，解压后运行 `ARONA.exe`，无需安装 Python。
- `source.zip`：源码和语音模块依赖快照，按 README 安装后运行。
- `SHA256SUMS.txt`：下载文件校验值。

微信、VB-CABLE 仍需在本机安装；Edge TTS 和远程模型需要网络。
第三方音色为近似音。网页登录/反爬可能阻止正文读取；封面理解需要实际支持视觉的模型。

自动发布前会运行七项回归测试，并检查干净目录内的便携包启动。
软件包不包含维护者的密钥、配置、聊天数据库、日志、训练资料或自定义语音预设。

本仓库采用独立版本号 v1.0.0，原 Windows 版本历史保留于 CHANGELOG。
