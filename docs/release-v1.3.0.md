# 什亭之匣 v1.3.0

汇总 v1.2.0 之后的本地更新，保留原程序图标与全部既有功能。

- 修复“发个语音喵一下”等明确声音请求、模型否认语音能力和暖场补答历史语音请求。明确请求绕过随机语音开关和概率；长内容分条发语音，失败只回退剩余文字。单字猫叫在本机角色 TTS 中规范为“喵呜”。
- 新增阿洛娜今日日记：默认北京时间22:00回顾真实活动并发布朋友圈，可附一张内置表情包。设置页支持开关、改时间、本地预览和「立即发布今日日记」一键发布；先落盘、按日去重，结果不明时不会自动重复发表。
- 日记仅提供活动统计，不公开群名、昵称和聊天原文。软件运行且微信可用时执行；发行版默认关闭，请按需开启。
- Token 优化：分类/摘要不重复携带整段历史，正常多轮对话保留；分享按需查更早偏好，机器人自己的分享不再触发循环判断，模型可预约重查。精简重复规则及证据，优化稳定前缀，记录真实缓存命中，无每日配额。
- 22个检索服务及可选百度百科，单个来源拒绝访问时继续其他来源；区分拒绝、超时、无结果，保留原网页和 RAG 入库。修复 Mon3tr 等条目召回。
- 同一聊天保留真实 user/assistant 多轮记录，Agent 共用会话，不把草稿当成已发回答。气泡优先自然停顿，保留换行，减少零碎短句。
- 本机角色音色支持轻度清晰度调整。本机角色权重、参考录音、用户预设均不随发行包上传；没有本机文件时请使用可用音色。

朋友圈使用实际可访问的微信4.x原生控件，正文和配图编辑流程已在本机验证，未提前发布测试朋友圈。微信更新或控件变化时可能失败；此时保存草稿并显示实际状态。缺少纯文字发表入口的版本需要保留配图选项。正式发布结果以自己账号的朋友圈记录核对，未确认时不重复发送。

发行文件包含源码、Windows x64 ZIP 和 SHA256SUMS。配置、密钥、日志、数据库、日记及私人语音文件全部排除。
