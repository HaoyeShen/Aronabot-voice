# 什亭之匣 v1.3.1

- 调整回复逻辑：持续监听、保存上下文，普通消息先按默认3%概率触发，再由接入模型判断；@和确认的连续追问直接回复。关键词不再单独跳过概率，各群/好友可自定义，保留旧唤醒方式开关。
- 新增按会话开关的跨聊天记忆；双方都启用才共享近期发言和已有摘要，各聊天Agent保持独立。
- 新增名单内管理员私聊免密码跨聊天文字发送：精确目标与原文、备注/昵称核对、发送前复核、持久执行收据、结果不明不重发；成功发言计入目标上下文。
- 支持微信原生动画表情：检索全部已安装包页，由当前Agent预览实际画面并按语境选择，通过按住Alt再按E的原生面板发送，按消息类型与MD5验证。
- 修复搜索工具调用代码作为气泡外发；内部协议在Agent、解析和文字/引用发送层拦截，原始输出仍可审计。
- 入站动画表情实际画面直接附给同一Agent；普通小表情按其名称理解。保留Q版/官方立绘风格，移除旧扁平表情，日记配图增加轮换。
- 包含v1.3.0之后的本地更新：30站新闻来源、网页候选由模型审核且记录选择理由、可开关的朋友圈文字评论、五档推理强度（含高消耗）、角色扮演边界开关、回复时效、防重复发送与新闻跳过日志去重。
- 取消唱歌实验，保留正常语音回复、当前角色和音色配置、语音结尾保护及失败文字回退。

升级前备份并保留原`data/`。发布包不包含个人配置、数据库、日志、语音预设、参考录音或本地语音模型；新安装可使用Edge音色，本机角色音色按原说明部署。

跨聊天记忆新安装默认关闭；管理员跨聊天功能仅限名单内成员私聊，群聊管理指令仍要求密码验证。朋友圈日记和评论新安装默认关闭。实机调试仅限`test`群；朋友圈对真实好友的自动评论不作为调试操作。
