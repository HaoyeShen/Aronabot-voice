# 角色称呼与切换

对他人的称呼默认遵循当前角色的核心设定、关系设定和说话方式。内置阿洛娜/普拉娜的设定仍使用「昵称＋老师」，其他角色不会继承这条全局强制规则。

在人格页面编辑角色，可填写「对他人的称呼」：留空按角色设定决定；`博士` 是固定称呼；`{nickname}博士` 使用对方微信昵称。这个字段是明确的称呼选择。没有模型可用时，自定义角色使用不附带其他角色称呼的完整兜底，避免冒用身份。

默认人格与每个测试对象指定的人格独立。修改默认人格不会覆盖群聊已明确选择的角色，群聊角色在「测试对象」页面编辑。重名角色显示 ID 区分，刷新、重命名和删除后按 ID 恢复选择。

切换角色后保留历史事实，但不沿用旧角色的身份、称呼和 Agent 待办状态。生成回复或合成语音时发生切换，发送前会重新核对角色；已经发出的气泡无法撤销，新角色会用于后续回复。不会通过清空全部上下文实现切换。
