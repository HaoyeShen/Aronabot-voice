# 链接、关键词和语音维护说明

链接读取使用 `app/link_reader.py`，通过 HTTP 读取公开网页，不调用微信打开链接。
支持普通 HTTP(S) 地址、微信 appmsg 链接卡片和 finderFeed 视频号卡片。
网页提取优先 main/article，排除导航、脚本和样式；支持 gzip/deflate 和响应大小限制。
登录页、反爬、动态渲染页面可能无法提供正文，此时只依据卡片信息回复。
不下载或观看视频。视频号封面来自卡片中的公开封面地址，交给当前视觉模型描述；
模型无视觉能力、地址不可用或识别失败时，只保留标题，并明确这是推测。
最近四条上下文中的分享可以由“看看这个”等后续请求引用。

关键词命中后使用当前模型和最近六条上下文判断是否对机器人说话。
输出必须为 YES 才按关键词直接触发；公开讨论仍可按群聊概率和对象判断参与。模型失败回退现有本地称呼规则。
被 @ 的消息跳过该额外判断，仍走原有必回复链路。

新增配置默认由 ConfigStore 的 deep_merge 兼容旧配置：
`read_links`、`trigger_semantic_check`、`natural_voice` 默认 true，均可在“监听与回复”关闭。
语音保留原句标点，文字的标点替换不会再清除语音停顿。
内置音色仅迁移未修改过的旧参数；用户修改和自定义音色保留。
Edge TTS 仍是近似音，不能保证还原角色原声，也不支持自由的情绪/SSML 控制。
普拉娜可选本机角色模型，使用中文参考录音合成新回复；模型、参考素材和独立环境仅保存在本机。
试听、测试与自动语音共用后端选择，原 Edge 音色可保留备用，详见 [本机角色语音](character-voice.md)。
较长合成结束后，录音前再次打开目标会话并核对身份；身份不明时取消语音、回退文字。
独立语音字数上限、会话确认、音频末尾 0.6 秒静音、播放后至少 2 秒录制以及失败回退文字继续有效。

测试：原有六项测试，加 `tests/link_voice_test.py`、`tests/character_voice_test.py`。
实测脚本 `scripts/verify_shared_voice.py` 仅以 test 为目标，支持 link、preview、voice；
link --no-send 只读诊断。该脚本不会启动机器人后台监听；仅明确指定 news-test 时运行隔离的测试新闻。
