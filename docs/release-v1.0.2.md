# ARONA Voice v1.0.2 · 什亭之匣

包含 v1.0.1 之后的全部本地更新，软件图标与原有功能保留。

- 修复续聊超时在精确到期边界的浮点误差，保留到期退出行为。

- 公开讨论超过 4 人或连续超过 15 条有效发言后，可按原有概率参与；5 分钟间隔重新计数，各群独立，明确问他人仍避开。统一提示词及筛选规则。
- 空闲活跃气氛：默认每连续 30 分钟按 3% 判断，未命中再等完整周期。优先主题视频加短评，短评每条最多 15 字，含链接最多 3 个气泡；没有合适视频时简单问候。
- 每群可在「测试对象 → 编辑」设置独立视频主题，留空继承全局；主题变更取消旧候选。
- 视频仅用于空闲活跃气氛，普通回复及基沃托斯新闻不推送视频。校验近 7 天公开视频与官方短链，同群长期去重；联网、模型或发送失败均有兜底。
- 七项回归测试与干净 Windows 全页面启动检查；实际维护发送仅 test 群。

下载 windows-x64.zip 解压运行 ARONA.exe；source.zip 为源码，SHA256SUMS.txt 为校验文件。
包内不含账号配置、密钥、聊天记录、日志、自定义音色、训练资料或视频去重记录。

微信和 VB-CABLE 需本机安装；模型、Edge TTS 和哔哩哔哩接口依赖网络。接口限流或不可用时回退简单文字。语音音色为近似音。
