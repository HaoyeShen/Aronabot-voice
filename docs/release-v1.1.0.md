# ARONA Voice v1.1.0 · 什亭之匣

- 接入模型决定主动分享时机，并结合每群近期对话和独立主题生成搜索词、筛选视频或公开网页；支持分享经过视觉审核的公开图片链接。群内活跃时也能参与分享。
- 视频候选先核对主题与可访问性，再由模型审核，依据标题、简介、可用字幕和封面生成简短评论；实际发出的内容与视频信息写入本群上下文。
- 早报由模型补充各区检索词并总结可核实的新消息，继续按发布时间、群聊和历史去重；讨论回复先走概率，再结合模型判断对象。
- 普通回复默认每个气泡最多 25 字、一次最多 20 个气泡，可在设置中更改；优先在自然停顿处分割。视频或网页链接保持完整。
- 语音增加音频末尾静音和录制等待，保留目标会话核对与失败回退。普拉娜正确区分账号昵称 ARONA 与当前人格。
- 模型驱动按需搜索并读取公开网页，来源与正文进入本地 RAG；保留主题筛选、敏感词过滤、新闻时效和按群去重。

下载 Windows 包解压运行 ARONA.exe。微信、VB-CABLE 与可用的模型接口需要另行配置。公开网页、视频字幕和视觉模型可用性取决于来源及所选模型；机器人只读取可访问资料，不假装看过未读取的视频。读取微信消息使用本地数据库，不截图或录屏。用户配置、聊天记录、密钥、训练资料、自定义音色与分享历史不进入发布包。
