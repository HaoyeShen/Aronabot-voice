# 什亭之匣 v1.2.0

- 软件更名为「什亭之匣」，应用图标、桌面入口、窗口标题及便携版可执行文件同步更新。
- 每个群聊和私聊拥有独立 Agent，同一聊天的 AI 功能统一调度；新增微信式「Agent 对话」页面，按聊天/任务查看输入、回答、工具结果和失败状态。
- 新闻、视频、网页图片、文章及正文截图分享合并为 Agent 任务，封面与图片直接交给模型；不在任务外另外请求模型写短评或图片描述。真实发送继续核对会话和去重，新闻测试不占正式名额。
- 参考人物小传、关系边界与记忆使用方式优化聊天提示词：自然承接上下文、适量语气词、少机械问候和结尾追问，求建议时认真回答；暖场需要真实话题或分享内容依据，没有合适内容就等待。
- 角色称呼遵循设定，人格可独立选择音色与参数；修复同名角色选择、生成期间切换角色、旧角色 Agent 状态沿用等问题。
- 完整记录每次模型调用的用途、输入、原始回答及错误，凭据脱敏；保留 @ 必回复、消息时效、气泡设置、引用定位、语音失败文字回退与末尾保护。
- 包含 v1.1.0 之后尚未发布的 @ 去重、搜索否定判断、角色语音能力认知、Agent 多轮续聊、后台模型退避、Windows 代理 DNS 延迟及网页媒体发送修复。

## 下载与升级

下载 `Shittim-Chest-v1.2.0-windows-x64.zip`，解压后运行 `什亭之匣.exe`；源码包可运行 `启动 什亭之匣.bat`。升级前关闭旧程序并备份原 `data/`，继续保留自己的配置与记忆，不要以空数据覆盖。

安装包不包含维护者的配置、API Key、数据库、日志、参考录音或角色模型权重。新安装提供 Edge 音色；已有本机角色模型继续按原数据目录使用，首次加载较慢。微信、VB-CABLE 和模型接口仍需在本机配置；上游接口过载、来源不可访问或平台风控时会如实失败/跳过，不保证每天都有可核实的新内容。
