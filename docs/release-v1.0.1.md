# ARONA Voice v1.0.1 · 什亭之匣

包含 v1.0.0 发布以来的全部本地功能更新，原图标与 11 个功能页面保留。

- 新增「测试对象 → 基沃托斯新闻 · 手动测试」：选择或填写群聊，点击「立即发送测试新闻」。默认 test，需先连接微信；后台采集发送，不占用当天正式名额，也不改写正式去重、重试和错误记录。
- 新闻扩展多语言官网、媒体和网页/RSS 来源；读取正文及原始发布时间，默认只接受近 24 小时资讯，长期去重，没有合格新资讯时按当前人格说明。
- 「监听与回复」新增可指定群聊的语音测试；明确请求声音时优先发送语音，否定及转述不误触发，失败回退文字。
- 修复最新消息引用定位及群名/备注不一致导致的语音失败；用会话 ID 统一识别，不在身份不明或错误会话强行发送。
- 增强阿洛娜知识回答、安慰与建议边界，群聊结合上下文判断消息对象；公开第三人称提及可以按概率参与。
- @ 成功回复后持续判断后续消息，无需重复 @；连续 5 条非对她说话或超时退出。超时默认 5 分钟，可在「监听与回复」调整。
- 保留入站方向、消息时效、@ 回复兜底、完整句拆分、语音独立字数及额外录音 1 秒、引用/语音失败回退和管理员验证。

## 下载与验证

- `windows-x64.zip`：Windows 10/11 便携版，解压运行 `ARONA.exe`，无需另装 Python。
- `source.zip`：源码及随包语音依赖；安装步骤见 README。
- `SHA256SUMS.txt`：文件校验值。

发布流程运行七项回归测试，并对干净 Windows 便携包执行全部页面启动检查。
维护调试仅使用 test 群。软件包不包含维护者配置、密钥、聊天数据库、日志、训练资料及自定义音色。

微信、VB-CABLE 需在本机安装，Edge TTS 与远程模型需要网络；音色为近似音。第三方网站登录或反爬可能影响正文读取；视频号仅按标题/封面推测，视觉理解需要支持视觉的模型。旧版已经清理的新闻历史无法恢复。
