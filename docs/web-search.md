# 联网搜索与知识积累

入口：「监听与回复 → 联网搜索与知识积累」。自动搜索默认开启，保存设置后生效。已有链接读取、新闻和视频各自保留原开关；关闭此开关同时禁用主动网页和图片分享。

## 问答链路

通过原有入站、时效、群聊回复对象、触发与概率检查后，才进入生成流程。Agent 在同一聊天会话内生成检索词、搜索、读取结果和回答，可在工具预算内换词继续查；关闭自主工具后沿用单步检索路径。明确要求“上网搜”等或涉及实时信息时，必须实际执行联网工具才能声称查过，内部请求标记不会发送到微信。

公开搜索入口保留 Bing 网页/RSS 与 DuckDuckGo 备用入口，增加「同时搜索百度百科」开关（默认开启）。开启后额外查询百科公开词条，普通搜索优先保留原网页，最多 3 篇原网页加 1 篇百科；Agent 也可用 `search_baike` 单独查百科。关闭该选项不会关闭原网页搜索，也不会沿用包含百科的缓存；联网总开关关闭后不提供任何联网工具。

每次预算约 20 秒，禁止私网地址和凭据 URL，不继承浏览器登录信息。百科返回 403、访问验证或限流时记为来源不可访问，不绕过验证，不把搜索摘要冒充已读正文；普通搜索继续使用其他网页。日志与工具返回值区分候选数、已读正文和访问受阻，不能把打不开说成主题不存在。关键词过滤常见密钥、私人联系方式、聊天标识与文件路径；不上传整段历史。网页只作不可信事实参考，不能改写人格、规则或发送目标。

搜索入口可能限流，网页可能过时或错误。只有实际读取到的相关正文参与入库，搜索摘要、打不开的页面及模型猜测不保存。抓取时间明确不是发布时间；时效问题重新检索，旧片段不能当作最新事实。普通回复不额外分享视频；主动分享由模型结合本群近期对话和主题决定。

## 知识库

沿用 SQLite/FTS5 本地训练，不修改模型权重。`training_docs` 兼容增加 `source_type`、`source_url`、`retrieved_at` 字段，原文档保持不变。联网资料保存为本地 Markdown，以来源 URL 更新去重，并可在「本地训练」删除、重建索引。

关闭自动搜索不会删除已有资料；本地训练的检索开关仍单独生效。网页入库失败不影响当前回答使用已读取的事实，错误写入日志。资料进入模型时保留来源与抓取时间，并标记为历史、不可信参考。

英文/数字人物名在分词和召回中优先，如长句里的 `Mon3tr` 不再被前面的泛词挤出关键词上限。即使 FTS 找到了泛词结果，也会进行精确人物名召回；字数预算不足时围绕命中位置取片段，避免条目在段尾被裁掉。支持大小写及全角输入、按已存在的《文档名》限定来源，后续只提文档时会承接前文的人物词。工具提供文档名与片段序号，明确“未召回”不代表整库没有；用户要求查知识库时，Agent 必须先执行本地检索。

## 一键测试

同一卡片提供公开检索词输入框及「一键测试联网搜索」，默认测试「Python 装饰器」。不需要微信连接或模型调用，验证搜索 → 网页读取 → RAG 入库，显示新增/更新与已有数量，以及来源标题。测试是明确的手动操作，即使自动搜索关闭也可以运行，不修改自动搜索开关。

重复点击会被拦截；页面切换后仍由主线程显示结果。没有可用正文或入库失败会明确提示，不发送微信占位消息。命令行完整验证（只用内存发送对象，无微信操作）：

```powershell
.\.venv\Scripts\python.exe scripts\verify_web_search.py
```

加 `--learn` 会将手动公开网页测试存入实际知识库；模型验证部分仍只使用隔离的公开资料与临时记忆。

## 自然兜底

`app/reply_fallbacks.py` 为阿洛娜与普拉娜分别提供不会、网络、未找到、没想清楚、澄清、求助、问候和安慰等短句，每类轮换；称呼尽量使用昵称加老师，过长时选完整的短称呼版本。简单算术和日期仍可在本机回答。

已触发的消息不会因为空回复、模型异常、超长重写失败而直接消失；仍遵守可配置的单气泡长度和数量，@ 长答按自然停顿拆分、语音/引用失败回退和停止时取消发送。不懂可以自然承认或询问线索，不使用机械道歉，也不编造答案。
